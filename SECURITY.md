# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The ZeroTrustX core team takes security seriously. If you discover a vulnerability or potential security flaw, please report it privately rather than opening a public GitHub issue.

1. **Email Reports:** Send vulnerability details to `security@zerotrustx.internal` or via our coordinated disclosure channel.
2. **Details to Include:**
   - Detailed description of the potential vulnerability
   - Proof-of-concept steps or payload
   - Impacted services (e.g. Policy Engine, WAF, DLP, Identity Service)
   - Suggested mitigations if known
3. **Response Timeline:**
   - Acknowledgment: within 24 hours
   - Triage and Severity Assignment: within 48 hours
   - Patch release: targeted within 7 days for critical findings

Thank you for helping keep the ZeroTrustX ecosystem secure.
